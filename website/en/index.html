Four steps to your first reading session

Set up once.
Then start reading.

This Chrome beta is not yet listed in the Chrome Web Store. Download the ZIP, extract it and load the extension manually.

01 / Get the extension

Extract the ZIP first.

Download the WestieLens extension ZIP and extract it to a permanent folder. Chrome loads the extension from that folder, so keep it on your computer.

02 / Load it into Chrome

Open the extensions page.

Paste this address into the Chrome address bar, then follow these steps.

chrome://extensions

  1. 1
    Turn on Developer mode

    Find the switch at the top right of the extensions page.

  2. 2
    Click Load unpacked

    Select the extension folder you just extracted.

  3. 3
    Find WestieLens

    Open the Extensions menu in the Chrome toolbar to find the extension.

03 / Configure it in the extension

Use your own API key.

Get a DeepSeek key ↗

Create an API key on the DeepSeek platform. In the extension, open Configure AI (配置 AI), enter your key, test the connection and save the settings. Do not submit your key on this website.

04 / Return to your reading

Select English. Click Analyze.

After installing, refresh any pages that were already open. Select a word or sentence, then click Analyze (分析) in the side panel. You can also open the panel from the context menu shown below.

The context-menu action opens a preview. The model is only called when you click Analyze.

A few things to know

Before you get started.

Is it free? Why do I need a key?

The source code and extension download are free. Analysis uses the official DeepSeek API, so you need your own API key and pay the associated API charges. WestieLens does not collect model usage payments.

Do I need Java or a server?

No. The extension connects directly to the official APIs and does not depend on the Java reference backend. Install it, add your key and start reading.

Where do my key and selected text go?

Your key is stored locally in your browser and used when requesting DeepSeek. Clicking Analyze sends the selected text to DeepSeek; word lookups also request a public dictionary. Dictionary audio and online voices may involve third-party services. This website does not ask for your key. Read the Privacy notice.

Why does text selection stop working after an update?

After updating or reloading the extension, refresh pages that were already open, then select text again. Browser internal pages, restricted store pages, PDFs and cross-origin iframes are not guaranteed to work.
