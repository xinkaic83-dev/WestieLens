隐私说明

更新日期：2026-10-31 · 插件版本 __VERSION__

本网站用于项目介绍、安装教程和文件下载，不接受或存储你的 DeepSeek API Key。请只在安装后的插件配置面板中填写 Key。

插件在本地保存什么？

  • API Key、模型和配置版本保存在浏览器的 chrome.storage.local 中，并限制为可信扩展上下文；不使用 chrome.storage.sync。
  • 朗读偏好独立保存在本地。选区、来源网页 URL 和分析缓存保存在 chrome.storage.session 中，不承诺跨浏览器重启保留。
  • 本地扩展存储不是加密保险箱，能访问你的浏览器配置或本机的人可能读取这些数据。

哪些操作会发送网络请求？

  • 仅划词会更新本地预览，不自动调用模型。点击分析后，分析文本及中文释义补全所需内容会发送至 DeepSeek 官方 API。Key 仅用于请求该服务。
  • 查词会将词语发送至 Free Dictionary API，不携带 DeepSeek Key。
  • 测试连接读取 DeepSeek 模型列表，不发送当前选区或调用模型生成。
  • 词典录音会从第三方音频地址加载；浏览器标记为在线的音色可能将朗读文本交给浏览器语音服务处理。

网站访问与托管

本介绍网站没有注册、登录、分析提交或 Key 输入功能，不添加自建统计脚本、广告追踪或第三方字体。网站仅展示使用截图，切换或放大图片不会调用 AI。复制地址功能仅在你点击按钮时向剪贴板写入扩展管理页地址。

网站使用 Cloudflare 托管。Cloudflare 可能为了提供、安全保护和运行托管服务而处理 IP、请求及访问日志等信息，具体以其隐私政策为准。点击 GitHub、Gitee 或 DeepSeek 等外部链接后，由对应服务处理你的访问。

如何清除数据？

插件中的“清除配置”会删除保存的 Key 和结果缓存，保留朗读偏好。卸载扩展会清除其浏览器存储。网站没有保存你的插件配置，因此不需要在网站提交删除申请。

费用、准确性与反馈

API 调用费用由你自己的服务商账户承担；测试连接成功不代表余额充足或生成请求一定成功。AI 输出仅供学习参考，可能不准确。外部服务的条款和隐私政策另行适用。

通过 GitHub Issues 反馈问题时，请勿附带 Key、敏感选区、私有网页地址或包含这些信息的截图。
