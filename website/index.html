01 / 下载插件文件

先解压，再安装。

下载 WestieLens 插件 ZIP 压缩包，解压到一个固定目录。Chrome 会从这个文件夹加载插件，请保留它。

02 / 在 Chrome 中加载

打开扩展程序管理页。

把下方地址复制到 Chrome 地址栏，再按顺序操作。

chrome://extensions

  1. 1
    开启“开发者模式”

    开关位于扩展管理页右上角。

  2. 2
    点击“加载已解压的扩展程序”

    选择刚才解压得到的插件文件夹。

  3. 3
    确认出现 WestieLens

    点击 Chrome 工具栏的扩展图标，即可找到插件。

03 / 在插件中配置

使用你自己的 Key。

获取 DeepSeek Key ↗

在 DeepSeek 开放平台创建 API Key，打开插件右上角的“配置 AI”，填入 Key，测试连接后点击“保存配置”。不要在本网站提交 Key。

04 / 回到正在读的网页

选中英文，点击分析。

安装后先刷新已打开的网页一次。选中单词或句子，再点击侧边栏里的“分析”；也可以通过下面的右键入口打开侧边栏。

右键打开后先显示选区预览，点击“分析”才会请求模型。

你可能还想知道

先把这些说明白。

插件免费吗？为什么还需要 Key？

WestieLens 的开源代码和本页安装包免费提供。分析能力调用 DeepSeek 官方 API，使用者需要自己的 Key，并承担相应 API 费用。项目不代收模型费用。

需要安装 Java 或购买服务器吗？

不需要。插件直接连接官方 API，不依赖项目中的 Java 参考后端。安装插件并配置 Key 后即可使用。

我的 Key 和阅读内容会发到哪里？

Key 保存在你浏览器的本地扩展存储中，请求 DeepSeek 时使用。点击分析后，所选文本会发给 DeepSeek；查词会请求公开词典。词典录音和在线语音可能涉及第三方服务。网站不会要求你填写 Key。详见隐私说明。

为什么更新后划词没有反应？

更新或重新加载插件后，刷新此前已经打开的网页一次，再划词即可。浏览器内部页、商店受限页、PDF 和跨域 iframe 暂不承诺支持。

可以修改或再分发吗？

可以按 GPLv3（仅第 3 版）使用、修改和分发。分发受 GPL 覆盖的版本时，需履行保留声明、注明修改和提供对应源码等义务。完整条件见许可证，第三方组件遵守各自许可。
