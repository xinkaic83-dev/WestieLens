## Chrome 手动试用清单

1. 安装包加载后，配置自己的 Key，测试连接并保存；确认密钥不回填输入框。
2. 同页选择单词、句子、另一单词，预览连续更新；点击分析后展示对应结果。
3. 右键“用 WestieLens 分析…”可打开当前页侧边栏，不自动产生模型生成请求。
4. A 打开并分析 → B/新页默认收起 → 返回 A，展开与结果保留；B 独立关闭不影响 A。
5. 两个独立窗口分别划词，不互相覆盖；导航/关闭标签页清理该页选区。
6. 切页停止朗读；完全退出 Chrome 后 AI 配置保留。此两项在此前实际试用有正向反馈，首发包建议复核。
7. 更新/重新加载插件后刷新旧网页一次，再划词应恢复；历史错误记录可清空后观察新错误。
