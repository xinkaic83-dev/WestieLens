## 1. 项目目标与范围

### 1.1 目标

通过真实网页阅读帮助用户理解英文词义、句子结构、语法与发音。面向个人自用，同时准备作为可展示的开发作品。

### 1.2 MVP v1.0

- 网页英文划词预览，用户点击“分析”才发送分析请求。
- 句子中文翻译、主干、主句与从句、句子成分及重点语法分区展示。
- 单词中文释义、词性、英美 IPA 与发音；词典不可用时 AI 兜底。
- 单词和句子英文朗读，口音、英文音色、语速和停止控制。
- 插件内配置、测试、保存和清除自己的 API Key。
- 标签页隔离、加载提示、可恢复错误重试、降级提示和有界缓存。
- 可复现构建、测试、安装说明与 GitHub CI。

### 1.3 后续候选，不纳入本轮验收

Edge 适配与验收、侧边栏原文成分着色、网页高亮联动、学习记录和收藏、独立云端语音服务。视频字幕、整页翻译、复杂学习计划、账号与云同步、Agent/RAG 也不属于 MVP。新增功能需另行确定范围。

## 4. 核心实现规范

### 4.1 浏览器扩展

#### 4.1.1 权限与入口

权限为 sidePanel、activeTab、storage、contextMenus；API Host 权限仅 api.deepseek.com 和 api.dictionaryapi.dev。Content Script 匹配 http/https 网页，不承诺浏览器内部页、商店页、PDF 或跨域 iframe 可用。

点击扩展图标打开原生侧边栏；右键菜单复用选区校验与存储通道。sidePanel.open 可用时，在用户手势回调中立即调用，避免异步等待丢失手势；不可用时仍保存选区，可使用图标入口。原生操作需要单独手动验收。

侧边栏按标签页独立打开：A 已展开时，切换未打开过面板的 B 或新建标签页，B 默认收起；切回 A 保留 A 的展开状态，B 可自行打开。禁用全局默认面板，为每个标签页配置独立的 sidepanel.html?tabId=<id>，不在创建/切换标签页时关闭整窗面板，也不清除其他页状态。展开状态由 Chrome 的标签页面板机制管理。依据：[Chrome tab-specific side panel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel#type-PanelOptions)。

右键菜单安装/启动初始化串行执行，先 update 已有菜单，仅在缺失时 create。create 返回 ID，异步错误必须在回调中读取 runtime.lastError，不能用 Promise.catch 代替；并发补建遇到重复 ID 时更新已有菜单。依据：[Chrome contextMenus.create](https://developer.chrome.com/docs/extensions/reference/api/contextMenus#method-create)。

#### 4.1.2 选区规则

selectionchange 防抖 500ms；trim 后至少包含一个英文字母，长度 1～500 字符。空选区和无英文选区不发送，超长选区在网页提示。过滤无效文本不表示清空上一条已保存的有效选区。

Background 从可信 sender 获取 tabId，拒绝伪造来源；仅接收顶层 http/https Content Script。保存成功回复 stored，暂时通信失败最多重试一次。上下文失效时清理监听和计时器并停止重试；重新加载扩展后旧网页需刷新一次。

#### 4.1.3 词句路由

单个英文单词（允许内部连字符或撇号）默认查词，多词默认分析；面板允许手动切换。显式 inputType 优先于自动路由。

### 4.2 服务职责

services/settings.ts 管理配置；http.ts 管理超时与脱敏错误；ai-service.ts 编排模型、词典、重试和降级；parsers.ts 做运行时校验；cache.ts 管理会话缓存；prompts.ts 保存 Prompt。Java backend 保留为独立参考，不新增本机代理依赖。

### 4.3 模型请求与输出校验

接口固定为 DeepSeek 官方服务；默认模型 deepseek-flash，实际可用模型通过“测试连接”读取。生成请求使用 JSON Output、thinking disabled。模型名可用不代表余额充足或生成必然成功。

translation 必须有效；clauses、syntaxComponents、grammarPoints 的 text 片段应逐字来自原文。mainSentence 可重构主干，只做类型和长度校验，不要求逐字出现。结构失败最多再调用一次；首次已有译文而后续失败时保留 partial，仅展示译文并提示，不缓存。

features 省略或为空数组使用 translation/clauses/syntax/grammar 全集；传子集时 translation 始终保留，仅校验和输出所请求的结构字段。

### 4.4 查词与朗读

词典优先提供词性、IPA、英文释义与录音，模型补充中文释义。词典故障或未命中时使用 AI 兜底，并标记 IPA 来源；中文补全临时失败可保留英文释义并提示，不缓存。鉴权、余额和配置错误需明确提示修正。

单词和句子共用英文朗读控件，句子读英文原文。提供美音/英音、音色及 0.75/0.9/1/1.1/1.25 倍速；默认系统合成，单词可选择词典录音优先，缺失或失败回退当前英文音色。没有英文音色时提示安装，不使用中文默认音色替代。

停止、切文本、切页和组件卸载取消朗读；偏好独立保存在 local 的 speechPreferences。浏览器在线音色可能由浏览器服务处理文本，当前没有集成独立付费云语音服务。声音质量以设备试听为准。

### 4.5 缓存

结果保存在 session，TTL 24 小时、最多 1000 项，序列化结果额外限制为 2,000,000 个字符。缓存键由供应商、模型、配置 revision、Prompt 版本、路由、features、原文等信息生成 SHA-256，不含密钥；partial 和英文释义降级结果不缓存。

保存或清除 AI 配置会移除结果缓存并使旧响应失效；旧请求不得回填新 revision 的缓存。同键进行中的请求合并；缓存读写失败不阻塞正常分析。会话缓存不承诺跨浏览器重启保留。

### 4.6 配置与通信边界

API Key 只存 chrome.storage.local，并先限制为 TRUSTED_CONTEXTS；设置失败不保存密钥。不使用 sync，不向 Content Script 或界面回传保存的密钥。输入框留空保存沿用已有密钥，清除配置同时清除结果缓存，保留朗读偏好。

Background 是模型与词典 API 唯一调用入口；仅本扩展 sidepanel.html 可触发分析或配置消息。密钥只发送到固定 DeepSeek 官方域名，词典请求不携带密钥；请求禁用重定向和 Cookie 携带。

不记录密钥、完整选区和原始供应商错误；local 不是加密保险箱。页面切换忽略旧响应不等于撤销已发出的付费请求。

### 4.7 错误与请求预算

网络失败、超时、非法输出、限流和服务故障展示中文提示，可恢复时显示重试。鉴权、余额、配置和不可恢复输入错误提示修正；不自动重试 HTTP 鉴权/余额/限流错误。具体错误结构与兼容数字码见 utils/api-types.ts 和 services/settings.ts，不要求每种直连错误都有数字码。

每次操作共享 120 秒总预算，模型单次按原文长度 >100 字符使用 45 秒，否则 15 秒；词典 8 秒、连接测试 15 秒，均包含 JSON 读取。分析期间每 20 秒调用轻量扩展 API，结束清理，不在空闲时保活。

## 5. 使用流程与体验

配置 AI → 测试连接 → 保存 → 网页划词 → 面板预览 → 点击分析 → 分区展示结果。连接测试只 GET /models，不发送选区、不生成、不自动保存草稿。

loading 显示骨架屏与“正在分析…”，不虚构服务内部阶段。同一页的新有效选区、导航或配置变更使旧分析响应失效；切到其他标签页保留本页状态和请求结果，不读其他页选区。切页停止朗读。仅 retryable=true 显示“重新尝试”。

## 6. 数据契约

运行时与 TypeScript 契约统一维护在 extension/utils/api-types.ts：

- 分析结果：text、translation、mainSentence、clauses、syntaxComponents、grammarPoints、partial、cached。
- 查词结果：word、phoneticUk/Us、audioUk/UsUrl、definitions、source、phoneticSource、fallbackTts、definitionLanguage（可选）、cached。
- 两者构成 AnalyzeResult 联合类型，当前通过 definitions 字段判别；边界先校验后渲染。
- 分析/配置响应为 `{ok:true,data}` 或 `{ok:false,error:{code?,message,retryable}}`。

## 7. Prompt 维护

当前 Prompt 位于 services/prompts.ts。调整结构、片段约束或含义时，同步修改解析器、相关测试及 ai-service.ts 的 PROMPT_VERSION。Prompt 版本独立于文档版本和产品版本；本轮文档整理不改变 Prompt 或缓存行为。

## 9. 扩展内部消息协议

### 9.1 消息类型表

新增消息须先登记本表，再修改 utils/messages.ts、Background 与测试。

| type | 来源与载荷 | 响应 |
|---|---|---|
| selection-updated | 可信 Content Script；text、length、url；tabId 由 sender 决定 | `{stored:boolean}` |
| get-latest-selection | SidePanel；必填 windowId | `{type:'latest-selection',tabId:number或null,selection:对象或null}` |
| analyze-requested | SidePanel；text、inputType、features（可选） | AnalyzeResult 成功响应或脱敏错误 |
| get-ai-settings | SidePanel；无 | 脱敏 SettingsStatus |
| save-ai-settings | SidePanel；apiKey（可选）、model | 脱敏 SettingsStatus |
| clear-ai-settings | SidePanel；无 | 清除后的脱敏 SettingsStatus |
| test-ai-connection | SidePanel；apiKey（可选）、model | `{models:string[],selectedAvailable:boolean}` 成功响应或错误 |

SettingsStatus 为 `{configured,model,revision}`。latest-selection 是读取请求的响应标记，不是另一个可主动发送的入站消息。

SidePanel 来源仅允许精确的 sidepanel.html，或该地址加唯一规范整数参数 ?tabId=<id>，不接受额外参数、hash 或其他页面。get-latest-selection 无新增载荷：有 tabId 参数的面板由 Background 从可信 sender.url 绑定所属标签页，并验证该标签页属于请求 windowId；没有参数的测试面板仍读取窗口活动标签页。有绑定的面板切页后不读取其他页选区，也不清空自身结果。关闭/导航自己的标签页仍清理旧结果。

### 9.2 选区存储与隔离

session 键为 latestSelection:<tabId>，写入和清理按标签页串行。原生 SidePanel 由 URL 绑定自己的 tabId，并验证 windowId 归属；其他标签页变化不重置本页 UI。无绑定参数的测试面板仍跟随窗口活动标签页并在切页时清空。导航/关闭自己的标签页清理旧选区，异步读取与分析用版本号避免旧结果覆盖新状态。

## 10. SidePanel 状态与组件

### 10.1 状态机

idle → 有效选区 → preview → 点击分析 → loading → result 或 error。同一页的新选区、导航或配置变更按当前有效数据回到 idle/preview；切到其他页保留本页结果。result/error 不自动发起下一次分析。

### 10.2 组件

SelectionPreviewCard 展示预览与模式；Skeleton 显示 loading；SentenceResultCard/WordResultCard 展示结果；ErrorCard 显示错误与条件重试；AiSettingsCard 管理配置；EnglishReader 管理朗读。

### 10.3 交互规则

loading 禁用分析与模式切换；结果/错误状态允许重新分析。缓存、结构降级和释义来源明确提示，底部常驻 AI 免责声明。原生侧边栏宽度与右键菜单使用情况单独验收。
