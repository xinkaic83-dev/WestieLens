## 插件构建与发布

WXT 的 build:publicAssets hook 从仓库根目录复制三份许可材料，产物中对应为 LICENSE.txt、NOTICE、THIRD_PARTY_NOTICES.txt；所有文件均无需用户密钥。

发布时应同时提供与安装包匹配的源码归档或接收者可访问的源码地址，保留版本号、提交 ID 与构建步骤。仓库仍为私有时，只放 GitHub 链接不等于已向所有接收者提供源码；不要先公开安装包而不给接收者相应源码。

开发后端保留为参考实现，若另行分发其 JAR 或容器，还需处理该产物包含的 Java 依赖许可材料；插件的第三方声明不代表后端已完成这一项。
